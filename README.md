# Sales Dashboard Analysis

## Overview

This project presents an interactive Sales Dashboard created to analyze sales performance and provide meaningful business insights. The dashboard helps users monitor key metrics, identify sales trends, compare product performance, and support data-driven decision-making.

## Objectives

* Analyze overall sales performance.
* Track monthly sales trends.
* Compare sales across categories and sub-categories.
* Identify top-performing states and products.
* Visualize sales data using interactive charts and dashboards.

## Dashboard Features

* Total Sales
* Sales Target Achievement
* Monthly Sales Trend
* Sales by Category
* Sales by Sub-Category
* Geographic Sales Analysis
* Profit vs Quantity Analysis
* Sales Distribution
* Interactive filters and slicers

## Tools Used

* Microsoft Excel / Power BI
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning and Transformation
* Data Visualization

## Key Insights

* Identified the highest-performing product categories.
* Compared actual sales with sales targets.
* Analyzed monthly sales patterns.
* Found regions contributing the highest sales.
* Evaluated profit and quantity across different products.
